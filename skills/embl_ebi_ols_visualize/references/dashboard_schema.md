# Dashboard JSON Data Contract (`dashboard_schema.md`)

## 1. Overview

This document specifies the normalized JSON contract generated by `scripts/visualize_hierarchy.py` and `scripts/visualize_ontology.py` and consumed by `scripts/generate_dashboard.py` to populate `window.__OLS_DATA__` inside `dashboard.html`.

---

## 3. Semantic Edge Style Specifications

| Relation Type | `is_hierarchical` | Stroke Pattern | Hex Color | Semantic Meaning |
| :--- | :--- | :--- | :--- | :--- |
| `subClassOf` / `is_a` | `false` | Solid (`none`) | `#0D9488` (Vibrant Teal) | Direct taxonomic class specialization |
| `part_of` | `true` | Dashed (`6,4`) | `#D97706` (Energetic Amber) | Meronymic structural or processual containment |
| `develops_from` / `derives_from` | `true` | Dashed (`8,4`) | `#059669` (Functional Emerald) | Developmental or anatomical lineage derivation |
| `occurs_in` / `located_in` | `true` | Dotted (`3,3`) | `#4F46E5` (Vivid Indigo) | Spatial or compartmental localization |
| `regulates` / other | `true` | Dotted (`4,3`) | `#E11D48` (Deep Rose) | Biological regulation or custom object property |
